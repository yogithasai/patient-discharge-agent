# Patient Post-Discharge AI Agent

An AI-powered healthcare follow-up system that monitors discharged patients, assesses recovery progress, detects potential health risks, and alerts healthcare staff when intervention is required.

## Features
- Patient Registration
- Follow-Up Assessment
- Risk Detection
- AI-Powered Analysis (Gemini)
- Healthcare Alerts
- Dashboard & Analytics

## Tech Stack
- Python
- Streamlit
- Gemini API
- SQLite
- LangGraph (planned)
